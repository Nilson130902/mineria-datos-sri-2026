## 📌 Descripción del Proyecto
Este repositorio contiene la solución práctica de minería de datos aplicada al registro oficial de vehículos nuevos del Servicio de Rentas Internas (SRI) del Ecuador (241,364 registros). Aplicando la metodología KDD, se construyó un pipeline completo de análisis exploratorio, preprocesamiento, *feature engineering* y modelado supervisado para predecir si una transacción corresponde a una **Persona Natural** o **Persona Jurídica (Empresa)**.
